CONFIANZA Y TRANSPARENCIA

100% Seguro y Reversible

Sin cajas negras ni scripts peligrosos que rompen Windows Update o disparan falsos positivos.

01

Código abierto auditable

Todo el código fuente en C# y JS está publicado en GitHub para que cualquiera pueda revisarlo o compilarlo desde cero.

02

Sin inyección en juegos

Los FPS se leen mediante eventos ETW de solo lectura de Windows (DXGI/D3D9). Nunca engancha ni modifica memoria de un juego.

03

Centro de Restauración

Cada ajuste guarda su valor exacto previo para deshacerlo en 1 clic, además de crear Puntos de Restauración nativos de Windows.

04

0 telemetría oculta

PulseCore no recolecta ni envía datos personales. La única consulta externa opcional es verificar si hay una nueva release en GitHub.

PREGUNTAS FRECUENTES

Todo lo que necesitás saber

Sí. PulseCore no inyecta DLLs ni lee/modifica memoria de ningún juego. El contador de FPS y 1% Low usa ETW (Event Tracing for Windows) en modo pasivo de solo lectura, y el módulo Fortnite Pro solo edita el archivo local de configuración GameUserSettings.ini.

Windows exige elevación para tres tareas legítimas del sistema: leer temperaturas reales de CPU/GPU desde los sensores de hardware (LibreHardwareMonitor), escuchar eventos ETW de DXGI para el contador de FPS, y aplicar cambios reales como planes de energía, DNS, limpieza de C:\Windows\Temp o SFC/DISM.

Sí, todo es reversible. El Centro de Restauración registra el valor exacto anterior de cada ajuste del Check-up y Debloat para deshacerlo en 1 clic, el Modo Juego restaura tu plan de energía al cerrar la partida, y Fortnite Pro guarda tu GameUserSettings.original.ini intacto antes del primer cambio.
