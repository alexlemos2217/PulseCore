Ingeniería Transparente

Seguridad diseñada desde la primera línea

Cada ajuste en PulseCore fue pensado para proteger tu cuenta, tu privacidad y la integridad de Windows.

0% Inyección en Juegos

El Mini-HUD lee eventos de presentación de frames vía ETW de Windows sin tocar la memoria ni inyectar DLLs en ningún juego.

Reversible al 100%

Todos los cambios de Registro, Debloat y Fortnite crean respaldo previo y se pueden deshacer desde el Centro de Restauración.

Código Abierto Auditable

Todo el código fuente en C#, WPF y los scripts del instalador están públicos en GitHub para que cualquiera pueda revisarlos.

Permisos Admin Explicados

Solo solicita elevación UAC para leer sensores de hardware, abrir la sesión ETW de FPS, cambiar DNS y ejecutar SFC/DISM.

Sí. A diferencia de otros overlays que inyectan librerías DLL dentro del proceso del juego, PulseCore mide los FPS y el 1% Low utilizando ETW (Event Tracing for Windows), una interfaz oficial del propio sistema operativo. No modifica binarios ni memoria de ningún juego.

Windows exige privilegios elevados para acceder a los sensores de temperatura de CPU/GPU, iniciar sesiones ETW de conteo de frames, cambiar servidores DNS en el adaptador de red, alternar planes de energía y ejecutar herramientas de reparación como SFC /scannow y DISM.

Totalmente. PulseCore incluye un Centro de Restauración integrado para revertir ajustes de Debloat, Registro y DNS en un clic, además de permitir crear Puntos de Restauración nativos de Windows y respaldos automáticos de tu configuración de Fortnite.
